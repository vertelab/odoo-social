# ── LinkedIn — cookie-based auth (linkedin-api by Tom Quirk) ─────────────
# https://github.com/tomquirk/linkedin-api
# OBS: linkedin-api 2.3.1 deklarerar lxml<6.0.0 i sin metadata, men
# importerar och kor fint med lxml 6.1.3 (verifierat 2026-09-15 pa key).
# repo_apply slar ihop ALLA repons requirements och loser om tradet —
# pip varnar for konflikten men blockerar inte. Pinnar vi lxml<6 har
# riskerar vi i stallet att bryta nagot annat som vill ha >=6. Lamna
# opinnat tills ett verkligt fel uppstar i LinkedIn-flodet.
linkedin-api

# ── LinkedIn — Playwright browser automation ─────────────────────────────
# Persistent browser context, session reuse, CAPTCHA-resistant.

# ocksa installeras separat:
#     playwright install chromium
#     playwright install-deps chromium   # systembibliotek (apt)
# Utan detta startar modulen men kraschar forst vid forsta sidladdning.
playwright
